# Zdjęcia

Wrzuć tutaj zdjęcia i podmień `ImagePlaceholder` na `<img>` w odpowiedniej stronie.

- `portret.jpg` — zdjęcie właścicielki (proporcje 4:5, min. 1200 px wysokości)
- `hero.jpg` — zdjęcie główne (masaż / gabinet)
- `gabinet-*.jpg` — wnętrze gabinetu
- `certyfikaty/*.jpg` — skany / zdjęcia certyfikatów (uzupełnij też `certificates` w `src/config/site.ts`)
