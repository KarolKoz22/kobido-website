# Kobido Studio — strona www

Szablon strony dla gabinetu masażu Kobido (Astro, statyczna strona).

```bash
npm install
npm run dev   # http://localhost:4321
```

Treści (telefon, cennik, certyfikaty, link do kalendarza) edytujesz w `src/config/site.ts`.
Szczegóły techniczne i instrukcja podpięcia Google Calendar: [CLAUDE.md](CLAUDE.md).
